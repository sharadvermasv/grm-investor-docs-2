# grm-investor-docs-2

Second store for GRM Overseas investor PDFs, served at
`https://www.grmrice.com/investor-documents/archive/<file>` through a rewrite in the grm-website repo.

Holds older filings recovered from the previous grmrice.com (the first store, `grm-investor-docs`,
is close to the 1 GB GitHub Pages limit). The filings index stays in `grm-investor-docs/data/investor-documents.json`.
